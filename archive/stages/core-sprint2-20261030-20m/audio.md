## 已核对的边界与依据

### 初始化、默认入口与旧入口

默认场景创建 Sim、UI 和角色后才调用 InitializeRoomAudio。BuildActors 先清 `_heardReactions` 没有顺序错误，该字典在字段初始化时已存在。新场景构造没有初始 Speech/ReactionRemaining，不会凭空触发开场反应声。

背景播放器先以零线性音量创建，再加载复制的 sanctuary-loop、设循环、Play 后暂停，最后按设置同步。没有在选择角色、近看、打开设置或每帧同步时重设 Stream/Play。--mute 和两个已有静音检查参数在音乐开始前就被识别。

进入 --legacy/--m01 等旧入口时，InteractionRoom._Ready 在音频初始化之前直接换场景。_ExitTree 的实例有效性判断覆盖尚未创建的播放器，未发现此路径空引用访问。

### 正在播放、候选与到期

原 0.65 秒间隔保留；待播候选每次重新读取当前反应，重新检查可见、未过期、有台词、未死亡、非准备进食、反应序号未听过，且资源存在。没有缓存一个已过期候选之后无条件补播的队列。

Playing 为真时，普通、拒绝、求助与同级伤声不能替换当前声；只有新的 coo-hurt 且当前基础级别低于100时能抢占并绕过间隔。选中者的 +1 不参与抢占判断。当前优先级即使保留到声结束，也不会永久阻止新声：Playing 为假且间隔已过就可以播放，并更新基础级别。

播放成功发起后才标记该反应已听。其他候选继续等到当前声结束，但若这段时间里反应过期、被新反应替换或角色不可见，下一次筛选会排除原候选。被高优先级声截断的已播声不会重新排队。

### 模态静音、音量为0与恢复

Ui 声音按钮同步调用 SetRoomMuted。关声当下 Stop，并登记所有当前反应序号，因此不依赖模态界面关闭之后才忽略旧声。SceneTree.ProcessFrame 另外持续同步音频，即使 `_Process` 因模态或暂停不调用 PlayRoomReactionVoice，也能继续忽略静音期间的反应。

音效音量为0使用同一忽略路径并把线性音量置零；恢复非零只允许新反应，不重新播放被忽略的声。音乐音量为0或全局静音时同时暂停流并置零；恢复后解除暂停，不重新调用 Play。有限音量限制到0..1；非有限输入回退已有默认值，没有把校验失败档当成合法档加载。

当前 UI 仍只有声音开/关，不存在小院独立滑块。因此音量0恢复的运行案例需要获授权的远端使用合法设置档或专门的场景检查入口，不能声称已经通过现有 UI 操作验证。

### 读档、重开与存档中的旧反应

LoadRoom 成功后替换 Sim，再 BuildActors 清字典；重开在保存成功后也替换 Sim。音频同步以 Sim 引用变化识别新世界，Stop 当前反应声、记录新世界现有 ReactionSerial、恢复间隔，并读取新设置。新世界的序号即使和旧世界碰巧一样，也不靠旧字典决定是否补播。

SceneTree.ProcessFrame 先于所有节点 _Process，所以正常下一帧的反应轮询前会完成上述处理。存档里 Speech/ReactionRemaining/ReactionSerial 是会序列化的字段，读回时统一记为已忽略符合“不把旧瞬时声音重放”的既有要求；之后 React 增加序号，新反应仍可播放。

读档失败不替换 Sim；重开前保存失败直接返回。这两条路径不会误触发音频“新世界”清理。背景音乐流没有随引用变化重启。全局声音开关仍是本次会话状态，读档同步的是存档中的音乐/音效音量；没有新增保存开关的需求或行为。

### 换场景与退出

_ExitTree 解除 ProcessFrame 订阅，停止并清空两个播放器。退出前保存失败会保留场景和声音，直到用户返回或明确选择不保存退出；这是当前保存失败流程，并非已退出后继续播声。

只读检索确认没有其他 InteractionRoom partial 定义同名 _ExitTree。退出清理也覆盖缺失音乐资源后只创建了空背景播放器，以及初始化尚未发生就转往 Main 的情况。未实际执行退出压力或原生音频线程验证。

## 真实覆盖边界

可见性和反应过期条件筛选的是“尚未开始播放”的声音。已经开始的短音效会正常完成，除了静音、世界替换、退出及高优先级伤声抢占；代码没有跟踪当前说话者并在近看切换或反应计时到0时立刻截尾。本轮没有把这个现有播放规则当成新缺陷，也没有新增“所有画外尾音立即切断”的规则。默认小院只有 home 区域，不能把没有入口的任意多区域迁移假设当成已复现问题。

Main.MilestoneAudio 仍是旧 M01 的隔离混音检查：SetProcess(false) 只暂停 Main 自动逻辑，Wait 使用 SceneTreeTimer；两首音乐跨边界后的采样先清旧缓冲，不能靠曲尾旧样本误报；短声有声音与结束两项断言；失败时 finally 移除录音效果。它假定没有外部人工操作 UI，不覆盖默认小院的声音队列、读档或静音按钮。

上述 Godot 行为依据只读的本地 `.tools/godot/Godot_v4.7.2-stable_mono_win64/GodotSharp/Api/Release/GodotSharp.xml`：ProcessFrame 先于各节点 _Process；StreamPaused 恢复时续播；设置 Stream 会停止旧声音；_ExitTree 在离开树时触发。没有把 XML 核对称为运行验证。
