# 历史归档

当前启动入口在 [仓库根目录](../README.md)。本目录保存历史事实、原机器路径和旧命令供查阅。历史启动批处理使用 `.cmd.disabled` 后缀。

- [legacy-engine](legacy-engine/) 保存原根工程及退出日常使用的旧引擎工具。
- [stages](stages/) 保存阶段交付、测试证据、场景样板截图和阶段源码快照。
- [superseded-docs](superseded-docs/) 保存旧入口、技术交接、原整理索引和差异副本。

历史目录中的引用按记录时的路径保留。通过 [迁移清单](../docs/project/migration-manifest.csv) 查找迁移后的原件或同 SHA-256 文件。完整原树仍可从基准提交 `4acb53f3be7be7975ee464491a6aa6009a4c8ed2` 查阅。
