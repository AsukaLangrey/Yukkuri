Yukkuri｜从小院到乐园：整合策划 v0.1
日期：2026-11-03（北京时间）
定位：主策划整合提案。用于逐步收敛体验、内容和制作顺序。
状态：新增机制、经济样例、节奏和验收阈值均为候选，不是用户已确认规则，不代表已实现或已证明好玩。
适用：先做自由模式的一个可玩切片；完整游戏仍保留养成经营、生态沙盒和直接互动方向。

一、策划判断与核心承诺

一句话：从一屋一庭和几只有脾气的悠悠开始，观察、照顾、教导它们，改变生活环境，看它们形成自己的习惯和关系，再把小院经营成有自己风格的乐园。

玩家主要收获三种满足：
1. 认识：我能认出这只悠悠，知道它与另一只有什么不同。
2. 影响：我的布置与相处，改变了它之后的行为。
3. 成长：原先需要亲自处理的事情逐渐能自主完成，我因此有余力发展庭院。

每次扩展必须增加一种新选择、一种可见生活变化或一种关系后果。仅提高容量与收入倍率不足以支撑扩展。
“可爱”和“系统多”是素材条件；真正需要验证的是玩家是否看懂因果、在意个体、愿意尝试另一种安排。

二、承接现有方向与新增边界

承接：自由模式优先；初始一屋一庭；土地取得与设施建设分开；个体具有实际需要、性格与关系；真实动作和物资交付才记成果。
承接：温馨可爱、生存压力、黑色幽默和残酷生态共存。庭院阶段以亲近和可挽救的麻烦建立感情，后续用环境、风险和遭遇扩展其他体验，不把整体游戏改成只有一种情绪。
承接：保留既有繁育与交易方向。新增不出售悠悠的经营路径，让留养与繁育交易都能继续发展。
承接：玩法在固定侧栏和场景内操作，无玩法弹窗，不因切换页面改变暂停状态；具体布局服从最新界面规范。
承接：不恢复已撤销的持续手动分工。玩家通过环境、示范、即时互动影响自主生活；新的任务承接机制不能暗中变成给每只油排班。

新增提案：生活证据驱动的委托收益；首次扩建的两种用途比较；以行为变化为主的短期成长目标；统一的玩法—美术—世界观—数值交付卡。
剧情章节、DIY工具、完整跨区生态、全部物种与高级治疗不进入首个切片；这只是验证顺序，不缩减完整游戏目标。

三、主策划的整合职责

所有功能先回答“玩家在什么情境下，做什么选择，得到什么反馈”，再拆给各领域。
世界观：解释对象的需要、行为边界和社会关系；不能由历史设定直接推导一整套未经验证的操作。
玩法：明确可执行动作、条件、代价、结果、替代办法和失败后的接续。
美术与声音：让玩家能看见、听见正在发生的事，优先支持识别和操作，再丰富装饰。
数值：控制选择的权衡与等待长度，不能用高消耗强迫玩家反复点同一个按钮。
主策划：检查上述四者是否描述同一件事，并维护版本依据、冲突和体验验证结果。

功能交付卡统一包含：体验目标；前置与玩家动作；自主行为；资源和时间；成功/中断/失败；画面与声音；侧栏信息；存读档后保持的事实；验证方法；当前状态。
每个新增状态必须进入行为、反馈或后续选择。只在面板增加一项数字的设计暂缓。

四、三层循环

即时循环（约30秒—3分钟，体验目标）：
观察一个具体行为 → 判断需要或阻碍 → 调整摆放/递送/示范/互动 → 看见结果 → 留下可追踪经历。
例：两只油挤在同一个食盆附近。玩家可以分开放盆，也可以调整接近空间。之后实际通行与进食变化让玩家理解布置的作用。
普通需要允许自主解决，玩家可以欣赏和观察；不要求每次饥饿都手动喂食。

经营循环（约1—3游戏日）：
维持食水与休息 → 形成自主生活或培养成果 → 取得可解释的收益 → 在设施、储备与扩建之间取舍 → 接受更复杂的生活关系。
短期成果可以是第一次独立清洁、一次实际照护、连续稳定使用食水点，不能要求先养到成年才出现回报。

长期循环（跨多个游戏日与季节）：
认识个体 → 培养与建立关系 → 选择留养、繁育、交易或接纳 → 改造庭院 → 遇到新环境和族群问题 → 形成属于这份存档的故事。
长期发展由生活方式与环境差异驱动，避免只有“更多油、更多盆、更高单价”。

五、首个30分钟可玩切片

基准：常速1游戏日600秒；以下分钟为排除暂停和读说明后的主动体验预算，不是脚本强制时刻。
开局沿用现有小铃、松果、豆豆作为设计样本；需要核对当前存档模板，不直接改写人物性格。三只应具备可观察差异，但这些差异不能仅靠角色介绍宣告。

0—5分钟：认识小院。
画面同时能找到小屋、食水角和活动草地。玩家完成一次补给或摆放，随后看到自主进食/饮水。
侧栏只在需要时解释当前阻碍，避免把所有状态一次铺开成为教程。
回报：玩家能辨认至少一只悠悠，并发现一处性格或行为差异。

5—12分钟：第一次影响生活。
提供一个自然生活中的小麻烦，例如需要清理的脏污或不方便接近的食水摆放；不能靠故意破坏寻路制造挑战。
玩家可以直接处理，也可以先示范并等候适合的自主尝试。记录实际完成者与结果，不把示范算作学会。
回报：一次看得懂的前后变化，以及后续是否重复出现的观察线索。

12—20分钟：第一次经营选择。
展示一种无需出售悠悠、无需扩建即可完成的基础委托。允许先观察条件，不强制接单，不引入新的在场个体。
同时展示首扩完整成本，包括土地、整理和第一项设施，以及建成后仍需承担的补给。
回报：玩家知道自己在攒什么，以及另一种选择会改变什么。

20—30分钟：做出首扩决定，看到生活用途。
目标是能负担一种完整的首扩，或明确自愿保留储备继续观察；不要求人人同时扩建。
菜园方向：获得一个生产试作空间，后续可减少部分口粮采购；不能解锁瞬间长出成熟庄稼。
照护花园方向：获得更便利的照护与安置空间，后续可承接相应委托；不能把普通树荫包装成自动治病。
这一段不要求豆豆成年。现行资料中的成年为35游戏日，常速约350分钟，不能与30分钟切片混用。

六、两种首扩用途与后续进程

菜园路径建议仍优先接在V04西南扩建口；照护花园作为相邻的后续选择保留。
为了验证选择价值，可以在纸面或测试配置比较两种首扩次序，不擅自宣布改变已确认的场地布局。

菜园：投入设施与照看时间，换取部分食物来源；保留饮水、护理等其他支出。小规模产量先替代采购，不能同时无限出售和无限供给。
照护花园：投入安置与护理条件，换取照护空间和相应服务资格；新增对象之前必须验证床位、食水与照护能力。
共同约束：首扩不提高生物数量是允许的，玩家可优先改善现有三只的生活。

首扩之后：先让一个扩建方向完整运转，再加入第二个方向、有限新个体和关系冲突。
季节阶段：沿用现有时钟，围绕保暖、储备、活动空间形成提前准备；新增季节内容需标为待制作，不把日历字段视为完整四季玩法。
外部世界阶段：接纳、野外发现、风险和研究复用个体规则；只有院内生活稳定且可解释后，才承担跨区保存与生态变化的成本。

七、世界观如何进入玩法

世界观中的脆弱身体 → 饮食、环境与照护有真实后果 → 美术表现困倦、姿势和求助 → 数值留出识别和干预时间。
个体性格和记忆 → 相同示范可能产生不同表现 → 动作、距离和回应体现差异 → 能力与愿意做分开，不用一次互动翻转性格。
家庭与亲缘 → 照护、竞争、跟随和离场会影响相处 → 用场景行为与事实记录讲故事 → 不凭空创建固定剧情强迫每局发生同一事件。
园区与外界规则 → 可以委托、交易、接纳和探索 → 通过固定侧栏接入 → 不新增以普通人类居民为中心的另一套经营游戏。

基础委托的设定包装候选：外部委托方为经过核实的培养/照护成果支付报酬；只需要事务入口，不需要先做游客系统。
委托方身份、长期动机和经济可持续性仍需内容设计。这是拟定的收入机制，不是从既有设定推导出的已确认事实。
表现风格与实际规则分开：含蓄表达不改变损伤、物资和关系后果。

八、美术与声音制作顺序

整体沿用真实3D、斜俯视的庭院方向；初始空间参考V04：小屋、树荫、分开的食水点、开放草地、可识别扩建口。
风格候选：暖土色与柔和绿色建立生活感；角色和关键道具通过轮廓、明度、动作区分，危险提示同时使用形状/文字，避免只靠颜色。
不在本策划中重新生成概念图或宣布现有资产已接入。

第一优先：角色可识别轮廓与饰物；正常移动、进食、饮水、休息、求助、清洁的可读表现；食水余量；门口与通路；地面污物与可清理反馈。
第二优先：看见学习前后差异的动作片段、同伴回应、成功后的短反馈、设施实际完成状态。
第三优先：多季节装饰、复杂远景、更多非交互摆件。新增装饰不能遮住门口、角色脸或点选目标。

声音分别承担：环境氛围、需求提醒、动作结果。重复需求提示设间隔，紧急情况可辨识但不形成持续噪声。
屋内观察使用项目后续采用的屋顶/查看方式，不能为展示细节引入全屏玩法弹窗。
美术验收先看正常游戏镜头中是否看得懂，再看特写。入口尺寸和饰物包络按V04简模验证，不从概念图推断碰撞已正确。

九、跨领域功能样例：第一次自主清洁

体验：玩家看到“它开始自己照顾小院了”。
世界观：会做、愿意做、目前能做是不同条件；性格和学习经历参与判断。
玩法：玩家示范或处理一次真实脏污；之后由现有自主判断决定尝试，必须接近并完成才记成果。受困、饥渴或路径受阻时可中断。
美术：朝向目标、接近、清理动作、污物消失与实际完成者反馈；禁止隔空清洁仍播放成功特效。
声音：短动作声与完成反馈，重复劳动降低提示频率。
数值：首次成功可为委托提供证据；熟练成长使用后续统一规则。示范次数不直接等于收入，指使者不获得劳动收益记录。
界面：右栏说明已发生的行为及中断原因，场景只突出本次重点。
接续：下一次相似情境能否自主处理，是长期培养的证据；一次成功不宣称永久学会。
验收：玩家能指出谁做了、为什么成功/没做，以及自己哪项操作可能有帮助。

十、经济与数值：先让一条账算得通

以下是纸面预算单位“元”的候选示例，未读取并替换实际商品表，也不是当前版本实测收益。
现有专题记录开局240元、50份食物、20份水；库存维持多久取决于实际年龄、消耗和价格，应在实现前逐项映射。

候选预算：
开局现金240；维持三只样本的每天补给预算20；基础有效委托每天最多40；安全储备60。
首扩土地140＋整理20＋首项设施80＝240。一次完整首扩后必须能保留储备。
若按每天为补给预留20计算，完成3天合格委托：240＋3×40－3×20＝300；首扩后剩60。
此例的30分钟可负担性依赖每天均完成委托，属于目标情景，不是保证。已有库存可以延后真实采购，但不能让同一份库存重复计入收益。
缺少一次委托时，三天余额260，首扩后仅20；此时提示储备不足，允许推迟扩建或采用更低成本方案，不通过强迫出售幼体填缺口。

基础委托候选规则：
从已有真实生活/培养证据中选取一项可达目标，不依赖未开放土地、高级牌照或购买新油。
领取后只接受新发生且满足条件的事件；每项证据只有一个交易身份，不能反复开关页面、存读档或重复使用同一事件刷报酬。
完成后自动记账并就地反馈；按游戏时间限制报酬预算，关闭游戏不结算，玩家不必按现实时间回来领奖。
后续熟练阶段，日常收入应能随真实自主生活产生，避免每天手动领取同一张表单。
奖励不鼓励制造伤病再治疗或反复弄脏再清洁；自然产生与人为制造的事件资格需在机制中明确记录。

普通难度兜底候选：现金不足时提供不可出售、不可换扩建资金的基本维生物资，使玩家能恢复基础循环。恢复条件不能要求先购买当前买不起的道具。
兜底触发与退出按实际缺口结算，不叠加储存为可交易财富；困难模式另行设计，不在本轮改变既有难度规则。

收益分类：生活委托用于开局现金流；种植优先降低采购；繁育/交易保持其独立收益与关系代价；高级服务在真实能力达到后开放。
防止同一动作被四种系统重复付费；不同经营道路比较净收益、操作时间、设施占地和风险，不能只比较销售额。

解锁冲突需单列：现有经营专题按累计售油收入200/500/1000解锁道具，这会限制非出售路径。
候选处理是给基本发展道具增加等价的生活/经营里程碑入口，原交易里程碑继续有效；特殊交易相关道具保留各自前置。
这是新增解锁提案，尚未覆盖现行规则。旧档保留已解锁内容，不把原累计售油收入伪装成全渠道收入。

十一、数值调试的统一口径

所有时间同时标注模拟秒、游戏日和常速现实时间；倍速只改变推进速度，不重复结算收益。
先量出三只样本的真实消耗、价格、可完成事件频率和建造时长，再替换上一节纸面假设。
收益用完成事件与账本核对；能力用实际行为证据核对；表现与真实状态共享来源。
危险应有能识别的预兆和至少一种当前资源可执行的应对。具体反应窗口按普通/高倍速体验验证，不在未测时承诺安全秒数。
不同时增加需求衰减、减少收入和提高设施成本；每次只调整可解释的一组变量，并保留前后结果。

十二、按结果逐步推进

第0步：锁定当前规则基线。
产物：现行食水、年龄、休息、清洁、培养、交易、解锁与信息展示表；标注旧文档的失效条款。
通过条件：策划使用的前置在实际默认入口可达，已撤销手动分工不再进入新设计；现有缺陷与设计缺口分开。

第1步：完成10分钟生活切片。
产物：一屋一庭、三只样本、真实食水与休息、一次可解释干预和一次行为证据。
通过条件：玩家能看懂需要、找到工具、看到前后变化；无须不停手喂才能维持普通开局。

第2步：完成30分钟经营切片。
产物：一条无需出售的现金流、完整首扩成本与储备提示、至少一个建成后可用的扩建方向。
通过条件：可算清实际收支；无出售也能推进；重复读档和重复点击不能凭空变钱；首扩确实改变生活。

第3步：完成跨日培养与关系。
产物：同一只油在相似情境下的变化、稳定自主生活与有限关系事件。
通过条件：玩家能记住个体，并能举出一件由自己的安排或相处引起的事情；不是只有能力条上涨。

第4步：扩展季节、族群与外界。
前置：既有循环在跨日、存读档和异常恢复中稳定；再增加接纳、风险、探索与更多内容。
本策划不承诺日历工期。某一步未证明体验成立，就返回调整该步，不靠增加系统数量绕过问题。

十三、如何判断“好玩”

程序验证与体验验证分开：收支守恒、路径可达、动作互斥和存档一致通过，不等于玩家觉得好玩。
首轮可用5位首次体验者作定性检查，不把小样本比例当成市场结论；本轮没有招募或联系他人。
候选观察目标：4/5能在5分钟内辨认一只悠悠并完成一次有目的的操作；4/5能在30分钟内解释首扩用途和主要代价；至少3/5主动提出一个后续想试的安排。
记录：每次求助原因、找不到入口的时间、无意义重复操作、资源危机、第一次自主行为、第一次经营选择及实际结束时机。
问的是“刚才发生了什么、你为什么这样做、下一步想试什么”，不要只问“好不好玩”。

失败判据与返工：
看不懂行为 → 先修因果反馈和状态一致性。
只顾补满数值 → 降低重复照护负担，改善自主生活与供给工具。
没有选择、只等钱 → 调整目标和机会成本，不能仅加速货币产出。
舍不得卖又无法发展 → 补齐非出售收入和道具解锁入口。
扩建只变大 → 给新增空间一个实际生活用途。
高倍速挂机优于全部互动 → 检查等待占比与主动决策价值，不用更密集的紧急事件处罚挂机。
