# 濒危时的繁育准备清理

新增 6 组远端检查源码，原开发机未编译、未运行。远端执行遵守 testing/PROTOCOL.md，记录机器和完整源码提交。

通过真实材料采集、强制准备和 Hurt 入口检查即时中断、近看托举/放稳救助、暂停和普通时间、存档续接、恢复债务及账目不重结。已开始孕育的夹具经真实操作和固定种子集合到达成功分支；只有已有恢复债务作为初始条件直接设置。

死亡检查区分“尚可救助的濒危取消准备”与“本次伤害立即死亡”，保留原有死因及孕育死亡结果。关闭致命伤害的情况仍要取消准备并允许救助。

没有验证画面、音效、鼠标命中或完整孕育平衡。暂停用例将 Hurt 视为外部同步事件，不代表暂停时玩家能绕过互动入口施加伤害。
