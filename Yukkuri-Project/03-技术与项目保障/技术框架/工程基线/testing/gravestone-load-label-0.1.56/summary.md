## 问题与复现

两个合法分叉存档可以由相同出生序列产生同一个孩子 ID，但孩子名字随各自母亲不同。
旧 BuildActors 清理角色和场景物件，却保留墓碑字典。PresentGravestones 找到同 ID 后复用旧节点，而标签只在创建时赋值，因此读入新世界后仍可能显示旧名字。

未修 main 在真实系统槽位按钮路径上重现 60 项中的 3 项标签失败：B 接在 A 后、同文件 B 再读、清场后先 B 再 A。其余 57 项通过。位置、状态、存档字节和节点数量没有在这些断言中失败。
这不是重复保存导致的名字数据损坏，也不是已经证明的通用内存泄漏。
