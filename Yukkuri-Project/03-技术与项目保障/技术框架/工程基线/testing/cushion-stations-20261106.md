## 原始缺陷与最小修复

默认软垫中心为 (-3.8,-3.4)。实际购买并放置补给站到 (-1.8,-3.4)，再 BeginPortableCarry → MovePortableCarry 到 (-2.6,-3.4) → ReleasePortableCarry → AdvanceInteractionPresentation，原版会完成重叠落地。先移动软垫再反向放置站点却会拒绝。

现有站点放置使用软垫宽 1.8、深 1.35 加站体半径 0.4 的扩展矩形。本次沿用这些已有常量与矩形边界，包括矩形角部，没有改成圆形或新增安全边距。MoveLooseObject 的目标与逐步路径检查均使用软垫专用站体判定；其它物品仍执行原来的 ClearOfStations(...,.2)。

兼容已有重叠状态：每个真实路径采样仅允许相对于当前点严格减小各重叠站体的最小穿入深度。允许连续小步退离，不要求一次退出；等深度横移、加深、穿过中心或进入另一站体均拒绝。一旦脱离，正常禁止重入。此处是为已有错误状态提供的工程恢复行为，不是新增策划数值。测试中的旧态是明确构造并通过 JSON 校验/读回的夹具，不是用户存档或历史兼容样本。
