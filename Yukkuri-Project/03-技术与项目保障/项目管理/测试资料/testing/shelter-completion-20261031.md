# 居所远端验证要求

仅供获授权的独立测试机运行。记录真实机器、完整40位源码提交、请求revision、运行日志与未测项。本轮源码以包含本文和居所实现的提交为准，不能用98de479、17bc81d或旧v53包出具本轮通过结论。

1. 构建Simulation、Game及新增Interaction.Shelters。先执行居所检查，再执行原SupplyStations、Continuity、Inventory、Family.Reproduction、Family.CareContinuity、DetachedStem、ActorGeometry及Save.Compatibility，最后按request.json保留的全部要求执行。保留失败证据，不修改断言迎合结果。
   本批版本v0.1.54须同时出现在窗口标题、小院顶栏、F3配置快照与启动日志；检查实际构建和导出包均保留此版本，不以旧exe读取新源码冒充新版。
2. 从商店花45元买小家，核对余额/仓库/已摆放总数。检查缺钱、满库存、无货摆放、重叠身体/树/河流、序号耗尽不消耗资源。旧无限标记不能免单。
3. 默认三只从前方和侧后方接近门口，受惊寻找开门空屋；逐帧确认不是穿墙或瞬移。竞争同屋不双占，关闭门口、插入障碍、急需食水或有实际家庭事务时重新判断。
4. 正常、幼体、老年、帽子/蝴蝶结及prototype-common外观，核对门宽、门高和屋顶。进入、屋内、退出不得沿用普通跳跃穿顶。真实相机射线不能越过墙/屋顶选中背面角色或食水；门框拉环须能实际命中。
5. 屋内关门后产生真实离屋需要，保持位置并提出出门求助。开门只改变门帘，后续实际经过门槛才释放。门口放盘、杯、球、遗体、器具后检查阻挡和移除后的恢复，不能关门夹穿身体。
6. 高信任呼唤、低信任拒绝、近期被人类伤害、正在吞咽/失能/临产分别检查；重复呼唤不刷信任、不复制效果。保留恐惧与事件记忆，房屋不代替食水或伤势护理。
7. 从门前低托救出失能个体，尝试快速拖过侧墙、后墙、屋顶；抛出、贴地拖动、滚动球和瓶具/器具搬运均不能跨墙。尚不能走动的个体仍需真实护理或援助。
8. 进门途中、屋内、出门途中、关闭门、被堵与暂停分别存读档。无离线结算、不多屋占同一住户、不赠房或库存。损坏身份/缺失住户/非法地基/非法进度应拒绝，原档保留。
9. 临产时先真实出屋再结算整窝；冷藏、死亡、跨区、搬运后释放自主预约，但现场身体不能凭空消失。所有交互期间检查世界时钟、库存与家庭状态连续。
10. 新版八类工具、普通观察、居所面板、F3对象选择和冻结读数互相切换；不残留上一只油/上一间屋的参数。右键、切工具、弹窗、失焦、重读档均取消摆放预览，已经放好的居所保留。

检查源码只是组件情境，不替代真实鼠标输入、画面或完整自由生活。当前本机未执行上述任何项目。
