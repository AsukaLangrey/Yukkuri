# 独立远程验证清单

所有项目状态为 `not_run`。本文件不授权启动程序，不是测试通过报告。

由主对话形成包含本轮全部修改的完整源码提交后，按 `testing/PROTOCOL.md` 在用户已授权的独立 Alice/dot 机器运行。不得在原开发机或其本机副本验证。每份报告必须记录机器、完整提交 SHA、配置/存档、实际命令、结果、日志位置及未测项；运行环境和提交不匹配时不能认定本轮通过。
