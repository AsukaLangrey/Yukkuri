## 已修的具体问题

1. **慢慢抽手仍可能变成急停。** `ContactMotion.cs` 原来只有法向外移速度超过 `StoppedSpeed=.8` 才会取消旧笔画。先沿表面以速度 5 移动，再以速度 .2 朝外移动，仍满足“速度低于 .8 且持续 .025 秒”的急停确认条件。现在根据实际向外方向取消笔画，不再要求抽手足够快；同时清掉上一次快揉的力度滤波余量，抽手当帧回到基础力度。主要向切线方向的斜向摩擦仍保留。
2. **慢速改向可完成旧方向的冲击。** 原来只在快速移动分支检查方向；减速途中反向或横向移动时，旧刹停仍能完成。现在在刹停判断前检查方向，沿用原 `.4` 方向一致性门槛，取消旧笔画。若改向后重新形成足够长的快速接触，仍可识别新笔画。很小的有效移动也计算单位方向，避免因旧的长度平方门槛被当成零方向。
3. **身体自身移动混入工具摩擦。** `ContactStrokeTracker` 原来只在鼠标完全不动时排除身体动画。一旦身体和鼠标同时移动，就用跨帧的身体局部接触坐标相减，可能把身体移动算成抚摸或擦拭。现在 `SampleStroke` 在当前姿态、当前相机下重新查询上一鼠标位置的接触点，再与当前鼠标位置比较。上一位置必须仍落在同一对象、部位、左右侧及可接触表面，否则重建基线，不跨空隙累计。实际接触历史仍由 tracker 管理，不因重投射恢复已经断开的笔画。
4. **工具路径漏掉卡顿样本保护。** 原来只有 `ContactMotion` 丢弃超过 .15 秒的样本，工具摩擦仍可能补算同一段鼠标距离。现在工具摩擦沿用同一时间有效范围；异常帧清空 tracker，输出零摩擦距离，恢复后先建立新基线。
5. **结束路径残留显示力度和方向。** `EndPointerGesture` 原来只重置 `ContactMotion`；模拟动作自己结束时仅清 `_mouseHeld` 等少数字段。现在松开、取消、连续动作启动失败及模拟动作结束统一清空两个 tracker、力度、方向、姿态。取消仍调用取消结算；正常松开仍调用原来的正常结算，托举落点与食水放置流程保留。
6. **错误目标和失焦显示。** 悬停到另一只油时不再显示上一目标的接触力度。按主对话要求，两个输入入口和悬停查询检查 `_windowFocused`，失焦时不接受操作也不显示可接触高亮。
7. **无效几何污染后续采样。** `ContactStrokeTracker` 增加坐标、比例和位移有限性检查，无效输入立即重置；不会把无效点留成下一帧基线。新加的 `previousLocalPoint` 是可选参数，已有调用形式保留。
