# 喝够后继续自主生活

1 组远端检查源码，原开发机未编译、未运行。按 testing/PROTOCOL.md 在独立远端记录机器、完整源码提交和未测项。

真实手持水入口、吞咽、前往地面水源、预留和入口、喝够并完成当前一口后，继续观察普通移动。保持同一手势 240 帧，不延后 DecisionIn，不清闲逛目标，不在推进期间修改位置、需求或摄入状态。检查旧手势不再占住姿态、两份水各结算一次；不要求最终停在目的地，也不要求一定返回起点。

它与 Interaction.Continuity 中隔离闲逛的 9 组合互补：Continuity 保留原固定终点断言，本项目检查产品本身仍能继续下一活动。未覆盖实机输入和画面。
