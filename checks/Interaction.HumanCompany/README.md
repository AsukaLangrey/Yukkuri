# 主动陪伴边界检查

本目录只新增检查源码，未在原开发机编译或运行。远端执行须遵守 testing/PROTOCOL.md，并记录机器和完整源码提交。

覆盖真实靠近和连续六秒记忆、离开后重积、每次只结算一次、亲密及身体门槛、安慰、暂停/近看/冷藏、收手立即停止收益及跨区、脚底永久失能、真实高伤害打断、同档续接及非法记录；另覆盖显式头部 Hurt 和离散 Flick 的部位戒备。

夹具隔离其他居民与场景食物，避免同伴、玩具和寻食占用动作。时间通过公开 Advance 与 AdvanceInteractionPresentation 推进，不调用私有陪伴函数，也不直接伪造成功记忆。收手测试特意保留三秒旧位置记忆，验证它不能替代真实输入；读档后无新输入也不能获得收益。非法状态用例先通过实际冷藏、受伤、死亡、干预入口得到可保存状态，再回填旧陪伴快照，排除夹具其他字段本身非法造成的假成功。局部戒备测试明确把即时疼痛/伤口设为恢复状态，以单独检验长期记忆，不声称这是产品内真实护理流程。

本检查不验证画面、声音、指针真实命中、用户是否理解请求、整体情绪平衡或长时多人玩法。
