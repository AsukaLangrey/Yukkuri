## 房间焦点与手感知

InteractionRoom.cs 初始化窗口焦点，订阅进出焦点。失焦取消手势，清除瞬时手感知和有效期，之后不采样手势或刷新旧鼠标位置。自主生活仍继续普通时间。恢复焦点只恢复输入资格，不自动恢复按住的手势。

InteractionRoom.Tools.cs 失焦隐藏落点提示。input 任务在输入入口、悬停提示使用同一 `_windowFocused` 字段。HasFocus/FocusEntered/FocusExited 的 API 名称已从本地 GodotSharp.xml 核对，没有启动引擎。

远端需测：按住接触、拿食水、托举、跟随练习中各自切走窗口；没有残留力度、自动再抓、手位置持续刷新或练习行程增加。按原设计安全结束手势；跟随的手记忆立即撤销。回到窗口后新接触可开始。

## 自主发声

原房间只播放选中角色的声音。改为在本帧可见角色中选择尚未播放、仍未过期的一次反应，受伤/害怕、求助、拒绝、普通回应分优先级，选中角色只用于同级优先。特写和异区角色由现有 actor.Visible 过滤，不在画外发声。

保留原全局 0.65 秒间隔；间隔内的反应不提前标已播放，实际播放后才记录。静音时记录为有意忽略，不在取消静音时补放。声音映射由 presentation 任务维护。已静态确认所用 wav 文件存在；没有听音或验证时序。

远端需测：不选中的油自行求助/不适能发声；多只同时反应依次播放而不重叠抢音；过期、异区和特写隐藏角色不补播；静音解除不重播旧反馈。

## 保存与重新开始

SaveRoom 返回成功/失败。presentation 任务接 UI：失败不替换当前 Sim、不清恢复状态，显示错误；成功才重新开始。普通退出保存失败时保留游戏和错误提示，不静默退出；允许用户明确点击“仍然退出，不保存”，避免磁盘不可写时无法退出。原“从备份恢复后不自动覆盖原件”的政策保留。

## 损坏存档

InteractionValidation 先校验 RoomObjects 的结构/身份，再检查个体预备入口引用，避免 null 条目先引发空引用而绕过备份回退。ActiveCue 非空时必须有对应 Learning 条目，不凭空补训练成绩。

Simulation.Smoke 新增合成损坏案例，检查受控拒绝、回退有效备份、拒绝覆盖损坏主档及文件原样保留。空学习字典且无当前练习仍合法。只写了测试源码，未执行，不能代替真实旧档兼容。

## 静止工具与自主行为

input 交接指出：只有空手 Touch 按零移动归还姿态，其余摩擦工具静止也阻止自主需求。主对话在 InteractionGestureOwnsPose 中补上 Stroke/Clean/Dry/CleanAccessory 只有实际摩擦才占用；Nuzzle 保留脸侧最初 0.45 秒邀请，之后静止等待不等同抓握。托举、按住、按压、护理等持续接触仍沿用原规则。新增 Input.Intent 合成案例检查普通饥饿时能离开静止工具自行吃饭，并保留 Hold/Press/Lift 对照，尚未执行。

第二次独立审查指出归还逻辑控制还不够：旧 stroke/nuzzle-ready 等短反应仍可能覆盖走动。补上只清理当前手势自己产生、反应序号仍匹配的旧姿势；不清除后来产生的取食、求助、受伤等反应。Nuzzle 直接反馈分支补记归属序号。新增检查断言等待后不残留摩擦姿态，并验证新戳碰反应不会被旧手势清理。未运行。

进一步补齐首次蹭脸回应的同帧交界：0.45 秒邀请完成后保留 0.35 秒短回应，然后静止工具归还动作与姿势；不会在刚生成 nuzzle-ready 的同一帧开始自主走动。检查从第一帧核对归还后的姿态，并单独要求首次回应仍有短暂姿态控制。0.35 秒是待远端观察的初始衔接值，不声称实际观感已确认。
