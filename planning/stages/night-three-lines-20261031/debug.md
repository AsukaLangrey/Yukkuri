# 调试面板与主协调接线

本轮用户要求“调试模式、面板开放所有参数，例如生命值，方便观测”。实现为显式F3开关的只读面板，不擅自引入任意数值改写。

已写源码（尚未编译或运行）：
- InteractionRoom.Debug.cs：非模态实时面板，读数最短刷新间隔250毫秒；当前油、全世界状态、模拟配置/当前输入三个范围；序列化所有公开状态而非字段白名单，中文名/完整路径筛选、160行分页、冻结读数、复制完整快照。冻结面板不暂停游戏，游戏暂停/近看规则保持；切换个体解除旧读数冻结，避免把旧个体状态标成新目标。
- Ui.cs：顶部调试入口、建立面板、定期刷新；工具快捷入口覆盖手掌、抚摸、拳头、火机、零食/饭/水。新Punch/Burn枚举由A提供，输入由B提供。
- B负责Input.cs的F3/Escape、文本输入焦点防误触、DebugContainsPoint遮挡判断；此处不抢写。
- 关键数值含生命、信任、恐惧、疼痛、馒馒来度、惊惧余波、饱食、水分、精力、安全感。其余参数可在完整范围查询。
- 救援用品购买面板接 BuyWaterRescueTool，使用B的ArmWaterRescueTool；购买时模态暂停自然时间，但纯钱/库存交易可执行，不临时篡改暂停绕过检查。成功救援消耗实际库存，失败保留；当前每份18元是原型参数。无限测试资源不扣钱但仍走购买入库。

待远端核对：F3开关不推进/暂停模拟、不改变资源；鼠标与键盘不穿透；选择新生/死亡/已安置个体、重开与读档能更新；筛选/分页/冻结仅影响显示；中文字符串可读；快照复制含完整范围而非当前160行；大群体时性能；实际窗口布局。静态审查不能证明这些效果通过。

第二批主协调源码：
- Vitals.cs普通面板常驻馒馒来、信任、生命、恐惧四项0—100监测，补性情标签；落水、救后恢复、惊惧余波分别提示。Ui.cs普通心情说明优先保留惊吓记忆，不在该阶段直接写“比较放心”。
- Debug.cs外层允许滚动，避免小窗口里摘要与控制挤出面板；新世界对象（读档/重开）即使复用相同个体ID也解除旧冻结。当前输入范围增补托举高度、救援工具、单击递食目标、进行中手势和真实入口接受状态，补新增参数中文名。
- Supplies.cs为主协调专用，接普通诱导用品购买（单价24、库存99、无限测试资源规则）；商店回家庭面板保留原选择。诱导执行与资格由A，家庭入口由B。未运行界面或规则测试。

第三批主协调源码：
- 新增专属 InteractionRoom.Intervention.cs，由 Vitals.cs 接到普通观察面板。真实落水时显示拿取救援用品或购买入口；拿取只装备，仍需点击对象才执行既有救援规则与库存结算。
- 选中正在施害者或被其追击者，均可看见当前冲突及制止入口。每次点击重新查询当前可见、同区、可行动的施害者，复用 ProtectFamilyChild / InterruptFamilyConflict，保持选中对象；暂停禁用且底层仍拒绝。停止危险不改写饥饿、伤势或关系。
- 已静态核对原观察栏滚动容器、输入遮挡与取消手势入口；新增按钮位于既有滚动栏，不占用场景输入区域。实际布局和鼠标操作仍需远端观察。

第四批主协调源码（进行中）：
- 顶部增加当前小院求助入口，读取模拟的 CurrentInteractionHelpTarget / InteractionHelpFor，按真实临危、落水、威胁排序，既有 HelpTargetId 只作同级参考。点击重验对象，回小院观察并将镜头移向对象；不跨区、不解除暂停、不自动使用用品。
- 制止按钮改用共享 CurrentInteractionThreatTarget 与 InterruptInteractionThreat，避免表现层自己猜失效旧目标或停止错误的危险行为。选中仍在啃食残躯的施害者时保留制止入口，但不向死亡个体发求救。
- 帮助说明补单击递食的收回条件、四项监测含义和状态恢复过程。调试冻结读数与暂停模拟的区别保持明确。

第五批调试对比（已提交39dc324）：
- 新增主协调专属 InteractionRoom.DebugComparison.cs，提供“记下当前读数”“只看变化/查看全部”“清除对照”。对比显示之前→当前、新增及已移除字段，继续支持中文/路径筛选和原分页；不修改或回退游戏状态。
- 冻结状态记录实际显示的快照；实时状态先读取一次再记录。切换范围、个体或世界对象清除对照，关闭后重新打开同一对象可继续比较；世界时间在近看中不推进不妨碍数值比较。
- 有唯一Id的数组项按Id配对，避免世界列表插入/移除后把另一只油当作同一只；重复/缺少Id退回索引，明确已移除行使用的是之前路径。内部路径分段转义，不因字典键含点或斜线碰撞。
- 快照失败时清空当前缓存并保留错误提示，切筛选或对比不会把读取失败误报为所有字段已删除。现有复制按钮仍复制该范围完整当前快照。
- 只作代码与状态流静态审查；实际控件布局、滚动、快照比较和剪贴板仍未执行。
第五批整合补充：普通观察面板不再只在惊惧余波达到12时提示；小幅余波仍可见，疼痛或恐惧尚未安定时也给出对应说明，避免行为仍谨慎而面板看似完全正常。新增保护收益时间的中文标签。均为只读显示，未执行界面或游戏验证。

第六批主协调接线（进行中）：
- 小院补护理用品购买弹窗，复用模拟公开的原15元3包常量和BuyMedicine；补给与拿工具分开，有限资源模式没有库存时不能装备。沿用现有测试无限资源语义，并如实标明该模式护理不扣库存，不伪称改变了资源规则。
- 危急状态显示当前模拟救治剩余时间，并提供拿护理用品入口；仍需真实按住适用伤处完成护理。落水优先拿救援用品，固定者按Box/Wrap/Frame/Hanging拿正确解除工具；离水恢复者可直接拿毛巾。均不自动执行治疗、解除或擦干，不增加隐藏传送。
- 即时介入控件移到身体状态说明之后，置于普通关系条之前，减少危机时翻找；仍使用原滚动面板。所有动作的暂停、接触、目标、资源资格继续由原入口执行。
- 本批仅源码接线及静态审查。弹窗布局、鼠标取消、滚动和危急场景尚待授权远端实际验证。
