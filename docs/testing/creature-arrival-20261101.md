# v0.1.55 新油投放

入口：左侧“投放新油”，或商店“购入新油”。可选灵梦/魔理沙、幼体/成体、母方/父方，名字可留空。每只暂定30元，与现有付费小院一致，选择落点时不扣款，实际成功投放才扣一次。一次选择只投放一只。

已完成源码接线及静态审查；原开发机未运行编译、检查或游戏。本次新增内容不沿用 d13140e 的远端通过结论。

远端执行新增 `checks/Interaction.CreatureArrival`，并运行既有存档、库存、居所和互动检查。新增检查覆盖身份与完整存档往返、八种种类/年龄/角色组合、准确扣费、失败快照不变、空场景、当前区域、人数上限、水面/边界/障碍阻挡。暂无执行结果。

实机需核对：

- 两个入口均可打开；未选中旧油、原油全部收容或死亡时仍能投放。
- 投放前出现绿/红落点框。水面、岸边、树、物件、身体、居所内外墙不能叠放；挡住视线的物件不能穿透点击。
- 左键只增加一只，准确扣30元并选中新油；模型、年龄、姓名正确，可以正常互动、自主活动和参与后续照护。
- 右键、Esc、切工具、开菜单、切近看、失焦、读档和重开后不残留投放状态，也不扣钱；暂停时不投放。
- 存档读回保留同一身体、饰品和身份，不重复扣款；投放幼体不播放分娩，不制造亲代、出生记录或好感奖励。
- 金额不足、场景达200只或落点被移动的物件占住时拒绝；更换合法落点后可重试。

游戏版本号已升至 v0.1.55。仅沿用既有序列化字段，不改存档格式。
