Soak 的 3,600 秒是模拟时间；几何组合中的不同帧率是数值采样。它们不等于游戏连续运行或渲染验收。两个较大 JSON 是明确标注的派生摘要，完整原始数据仅在当时云工作区，开发侧没有独立读取完整原始内容。
