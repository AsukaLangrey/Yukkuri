# 夜间改动：远端先测什么

这是测试交接，不是通过报告。本轮原开发机没有编译、运行检查、启动游戏或渲染。只在用户安排的独立远程机器及当地授权范围内执行；本文件不恢复已暂停的周期测试，也不授权原机运行。

## 固定来源

从交付包的 `SOURCE-REVISION.txt` 取得完整源码提交，核对 `source-manifest.json`、`SHA256SUMS.txt` 和该提交中的 `testing/request.json`。Git 工作副本固定到同一提交并取得实际 LFS 素材；ZIP 工作副本没有 `.git`，以交付清单记录来源。不要在测试中途更新源码。源码包不是可直接运行的游戏成品。

完整要求仍以 `testing/request.json` 和 `testing/PROTOCOL.md` 为准。本页只确定优先顺序，不删减必测检查。工具链按锁定文件；冻结 art03、旧 J/c10 报告均不能证明本轮通过。历史存档样本未提供时单独记缺项，不用合成档冒充历史档。`tools/check-night-repair-offline.ps1` 不是当前完整测试入口。

## 第一轮先排除阻断

1. 核对素材和构建。先保留首个编译/导入错误与完整命令，再判断哪些独立规则检查仍可执行。失败后不要改源码或降低断言来形成通过报告。
2. 优先运行 `Interaction.AffectionJourney`、`Interaction.AbuseJourney`、`Interaction.DetachedStem`、`Interaction.WaterSupport`、`Family.Reproduction` 和 `Family.Risk`，再完成请求中的其余检查。每项记录实际执行数量、种子、失败位置与时长。
3. 新开默认小院，确认能选择工具、显示油、地面食水和独立窝；打开“调试 · F3”，确认生命、信任、馒馒来、恐惧随实际状态变化。面板提供观察与读数比较，不是任意数值编辑器。
4. 真正操作鼠标：手掌拖起→移动→慢放、快速甩出、右键收回、切工具、暂停/恢复、失焦后回来。拳头连续命中出现连击；火机长按与离开接触面应及时改变反馈。零食点油递嘴、点空地放食，地面实物拿起后可递嘴或适用的培养瓶口。

## 三条最重要的完整旅程

| 旅程 | 实际操作与观察 | 不可替代的结果 |
| --- | --- | --- |
| 爱线与生育 | 默认三只自由行动，从陌生开始喂食、饮水、照护、陪伴，观察关系与安全感，再观察自主繁育。茎生与胎生分别走出生、实际食水份额、幼体保暖、母体恢复。 | 不能只把预填深关系的组件检查当作默认陌生旅程；不能只见到幼体就结束。照护不足导致恢复停住时，补给后应能继续。 |
| 虐线与余波 | 固定与自由移动各试火机；健康→实际伤痛→行动障碍/永久损伤→临危→死亡。低生命时另存一份场景，观察真实护理与后续。让其他油自由走入/走出见证范围。 | 当前工具必须真正碰到身体，尤其翻身后底部；零食可以吸引它，但不能消除伤势、恐惧、施害记忆。目击与仅听到声音的后果应有区别。 |
| 水域与救助 | 手掌把油实际放/扔进水里，观察挣扎、受阻、前进/逃脱、久泡恶化；另看粗心个体自主找水的失足事故，善恶同伴反应，再买救援用品并点击救起。 | 救援必须实际消耗一份用品；人为制造危险后不能刷感激。上岸仍口渴、受惊或有伤，需要后续照护；围观关系与短时守候不应无限重复结算。 |

普通规则检查可以使用明确标注的组件前置。实际游戏观察另从默认小院开始；无法在本次时段自然遇到的概率事件记“未观察到”，不要直接写不存在或通过。禁止把调好的性格、关系或身体条件隐去。

## 独立瓶养与物资

- 茎生过程观察支护、剪断、整窝身份、装瓶、搬放、真实瓶口食水、成熟出生和失败残留。母体死亡不应直接抹掉已独立的一窝；普通视图在死母体或未选对象时仍应能放下新的地面食水，再拿起递到瓶口；若存在阻断，记录是缺工具、库存、落点、前置还是输入不可达。
- 零食与正餐用途要分清。培养瓶只接受实际可用的食水来源，空份额、移开接触、右键、换工具不能重复补给或重复退款。
- 测试免费购买仍须增加真实库存。普通喂食、护理、救援、装瓶、繁育诱导分别观察成功一次消耗，失败不能凭空扣费或复制物品。当前经济平衡未验收。
- “同伴、家庭与照护”中的诱导和干预，分别观察准备、拒绝/失败、取消、实际孕育、母体负担和恢复；只看按钮可点不能代表完整流程。

## 表现与调试

近看油的眼睛、嘴部准备/入口/吞咽、泪水、帽檐、布结、发束、包扎与滴水，观察姿态转换时的遮挡、穿插和连续性。检查火机、饼干、护理垫与身体接触；不能只看静止模型。当前 Kenney 草花有实际接线；石头和食品候选不是已集成成果。

F3 分别查看选中对象、世界与模拟输入；试搜索、翻页、“记下当前读数”和“只看变化”。切换油、载入存档和切换范围后，对照应清除而不串到别的对象；面板不能替用户施加动作或修改状态。

暂停、近看、存读档、换区和工具取消覆盖以上旅程中的关键阶段。保留本次伤害/水域/孕育的身份与一次结算；读档不应重放旧特效或增加库存、关系、孩子。

## 回执

按 `testing/PROTOCOL.md` 写明远端机器、完整源码提交、请求版本、真实命令、通过/失败数量及未测项。规则通过、启动成功、视觉观察与两线完整完成分开写。附最短复现步骤和对应证据；第一轮未完成的必测项继续保留，不因本页优先级而省略。
